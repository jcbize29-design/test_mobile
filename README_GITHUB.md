# Strategic Shield Advisors — GitHub Pages

## Publish this website

1. Sign in to GitHub and create a new repository.
2. For the simplest free GitHub Pages setup, make the repository **Public**.
3. Extract this ZIP on your computer.
4. Upload the *contents* of the extracted folder to the repository root. Make sure `index.html` is directly in the repository root, not inside an extra nested folder. Keep the `assets` folder and all its contents.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch `main` and folder `/(root)`, then click **Save**.
8. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages.

## Important

- This is a static website; it does not require a build step.
- The website and its published files are public when using a public repository. Do not upload confidential information.
- The bundled video is about 20 MB. Check the published site on desktop and mobile, including all navigation buttons and video playback.
- To update the site later, upload/replace the changed files in the repository.
